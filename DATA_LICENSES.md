# Data licenses

This file lists the datasets and models this playbook uses, where they come from, and their licenses. The code in this repository is MIT-licensed. That license does not cover third-party data or models; each one keeps its own license, listed below.

## Datasets

| Dataset | Source | License | In this repo |
|---|---|---|---|
| Drone inspection photos (20 JPEGs, incidents INC900 to INC919) | Created by the author | MIT (this repository) | `data/drone-images/` (17 MB) |
| Incidents, assets, zones, technicians, image captions, asset logs and hand-labelled image features | Synthetic, generated by the author. All incidents, assets, zones, supervisors and technicians are fictional | MIT (this repository) | `data/*.csv`, `data/logs.jsonl`, `data/multimodal_image_features.json` (about 80 KB) |

## Models

| Model | Source | License | How it's used |
|---|---|---|---|
| all-MiniLM-L6-v2 | [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) | Apache-2.0 | Embeds the incident descriptions (384 dimensions). Downloaded from Hugging Face on first use |
| CLIP ViT-B/32 | [openai/clip-vit-base-patch32](https://huggingface.co/openai/clip-vit-base-patch32) | Not stated on the Hugging Face model card.
