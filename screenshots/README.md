# Screenshots

This folder contains screenshots demonstrating the functionality of the graph-augmented retrieval system.

## Streamlit UI Screenshots

The `streamlitUIscreenshots` folder contains images of the Streamlit user interface in action:

- Various search queries and their results
- Cache hits and misses
- Result rendering with images and related information
- Graph traversal visualizations

These screenshots demonstrate how users can interact with the system to perform multimodal queries over infrastructure incident data.

## Neo4j Graph Visualization Screenshots

The `neo4jscreenshots` folder contains images from the Neo4j Browser showing:

- The knowledge graph structure
- Nodes and relationships between incidents, assets, zones, and other entities
- Sample Cypher queries and their results
- Graph traversal patterns

These screenshots illustrate how the system structures and navigates relationships between different entities in the infrastructure domain.
